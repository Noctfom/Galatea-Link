# LLM 对局信息契约

本文档描述当前版本实际发送给 LLM 的信息、可见性边界和已知缺口

## 基本原则

- LLM 只能接收当前玩家可见的信息
- 对手隐藏卡片只保留区域、序号、表示形式和数量，不发送卡密、名称、属性或效果文本
- 曾经公开的对手手牌作为无序记忆保存，不绑定到具体手牌槽位
- 合法动作只在轮到当前玩家时发送
- LLM 只能返回 `legal_actions` 中存在的 `choice_id`
- 未进入 `DuelState` 的协议信息不会被假定或补全

## 当前完整提供的信息

- 当前事件类型
- 回合数、阶段和行动玩家
- 双方 LP
- 双方手牌、卡组、墓地、除外和额外卡组数量
- 己方手牌与场上卡片身份
- 双方墓地和其他公开卡片身份
- 公开卡片的当前攻击力、防御力、等级、种族、属性和类型
- 公开卡片及当前合法动作涉及卡片的名称与数据库效果文本
- 己方剩余主卡组和额外卡组的卡名与数量
- 已公开过的对手手牌无序记忆
- 当前已记录的连锁
- 最近已记录的公开发动历史
- 当前合法动作、目标实体和选择编号
- `llm_review` 与 `hybrid` 模式下的 Core 建议、最高动作概率和概率差值

## 当前部分可靠的信息

- 己方剩余卡组列表依赖移动和抽卡消息被正确解析
- 对手已知手牌记忆依赖公开、移动和离手消息被正确解析
- 当前攻击力、防御力和表示形式只包含状态机已经处理的变更消息
- 连锁历史目前偏向记录公开发动，不是完整的效果处理日志
- 卡片效果文本来自本地 `cards.cdb`，其语言和版本取决于当前数据库

## 当前尚未完整提供的信息

- 部分 `description_id` 对应的具体效果选项文本
- `SELECT_OPTION` 中每个选项的本地化语义
- 每张超量素材的公开身份，目前只有素材数量
- 装备对象、取对象关系和完整卡片关系图
- 卡片效果无效状态与效果适用状态
- 持续到回合结束或指定阶段的残留效果
- 一回合一次等效果使用记录
- 当前特殊召唤、攻击和发动限制
- 玩家提示、客户端提示和部分系统字符串
- 完整的伤害步骤、连锁结算和效果处理历史
- 胜负概率、未知卡概率分布和经过校准的 Core 置信度

## 卡片知识范围

当前请求会为场上、手牌、公开区域、连锁、近期历史和合法动作涉及的卡片提供效果文本

己方剩余卡组目前提供卡名和数量，但不会在每个请求里重复发送整副卡组所有效果文本，以避免显著增加延迟和上下文长度。后续应增加可缓存的牌组知识上下文，并让每次决策只发送状态增量

## 完整度结论

当前输入足以进行基础动作选择和验证 LLM 接入流程，但不足以保证复杂竞技决策始终有效。下一阶段应先补齐动作语义、公开素材、状态标记和效果历史，再实现依赖这些信息的自主动态介入
